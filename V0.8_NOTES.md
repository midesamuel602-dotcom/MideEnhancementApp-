# MEA v0.8

This release advances the processing architecture rather than pretending
that a browser fallback is neural AI.

## Added
- Dedicated processing worker
- Worker request/response queue
- Browser capability reporting
- Model-file type validation
- Model manifest example
- Model licensing/checksum checklist
- Engine test page
- Explicit neural-adapter contract

## Still required for true AI
A supported neural runtime plus compatible, licensed model weights must
execute inference. v0.8 does not bundle those weights.

## Free-user principle
The app remains designed with no subscription, credit system, or mandatory
paid API. If a future deployment uses a server for heavier models, that
would be an optional infrastructure choice, not a user paywall.
