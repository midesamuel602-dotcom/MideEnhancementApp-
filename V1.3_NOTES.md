# MEA v1.3

## Video
- Added adjustable mask padding.
- Added adjustable edge feathering.
- Improved boundary blending in the local fallback remover.
- Added safer process-button state handling.
- Added workspace reset helper.

## Architecture
- Added `ai/neural-adapter.js` as the explicit neural inference contract.
- Added `ai/mask-tools.js` for reusable mask operations.

## Important
This release still does not contain third-party neural model weights or a
neural inference runtime. The new adapter is an integration boundary, not a
claim that neural AI is installed.
